# Wednesday 25 November 2026 — The World in One Day

One front page, 1024×1024, summing up 25 November 2026's world news in a single image: 35 stories, 6 regions, every one dated Wednesday 25 November 2026.

- 3 lead stories: Shenzhou-24 carries Pakistan's first astronaut to Tiangong; Australia seals a Pacific security pact with Solomon Islands; Asian tech shares plunge (Taiex −7.57%).
- 10 medium stories with original flat-editorial illustrations.
- 22 more stories, a code-drawn dotted world map with 7 numbered pins, and a date-check box (wire cutoff 25 Nov 14:30 WIB; US PCE + GDP not yet released; 24 Nov stories such as the Nepal quake and Miss Universe deliberately left out).

`main.ts` copies `entry.png` to the output directory with PNG-magic, size (< 1 MiB), 1024×1024 dimension, and md5 byte-identical verification.
